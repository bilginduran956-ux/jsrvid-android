# JARVIS

Türkçe kişisel asistanın başlangıç projesi.

## İçerik
- Türkçe SpeechRecognizer
- Türkçe TextToSpeech
- Yerel komut yönlendirme
- Uygulama açma
- Web arama
- Fener
- Kamera
- Ses seviyesi
- Pil bilgisi
- Ayarlar
- OpenAI-compatible API desteği
- Foreground service altyapısı
- Accessibility service altyapısı
- GitHub Actions APK derleme

## Not
7/24 dinleme Android tarafından izin, pil ve foreground-service kurallarına tabidir. Erişilebilirlik servisi kullanıcı tarafından Android Ayarlarından ayrıca etkinleştirilmelidir.
